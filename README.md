# FMS-images

Генерация **PNG-скриншотов расписания уроков** из Excel-файлов — по одному
изображению на каждую **параллель**.

В книге `.xlsx` каждый лист соответствует одной параллели (например, `10`, `11`),
а внутри листа — расписание всех классов этой параллели с подгруппами, учителями
и аудиториями. Скрипт читает каждый лист, учитывает объединённые ячейки и
многострочные значения и сохраняет отдельный PNG для каждой параллели.

## Пример

Из `input/05.09.2026.xlsx` (листы `10` и `11`) получаются два изображения:

| Файл | Параллель |
|------|-----------|
| `output/05.09.2026_10.png` | 10-е классы |
| `output/05.09.2026_11.png` | 11-е классы |

![Пример расписания 10-х классов](output/05.09.2026_10.png)

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Использование

```bash
# обработать все .xlsx из каталога input/ -> output/
python generate.py

# конкретный файл
python generate.py input/05.09.2026.xlsx

# свои каталоги
python generate.py --input-dir input --output-dir output
```

Имя итогового файла: `<имя_книги>_<имя_листа>.png`.
Пустые листы пропускаются.

## Структура проекта

```
FMS-images/
├── generate.py        # логика xlsx -> PNG по листам-параллелям
├── painter/           # PIL-рендерер таблиц (перенесён из проекта FMS-bot)
│   ├── containers/    # Table, Cell, Text, Column, объединённые ячейки
│   └── fonts/         # шрифты Roboto
├── input/             # исходные .xlsx с расписанием
├── output/            # сгенерированные PNG
├── requirements.txt
└── README.md
```

## Как это работает

1. `openpyxl` открывает книгу и перебирает листы (каждый лист = параллель).
2. Значения ячеек и диапазоны `merged_cells` переносятся в таблицу `painter.Table`.
3. Объединённые диапазоны Excel воспроизводятся объединением соседних ячеек
   (сначала вертикальные полосы по столбцам, затем — по горизонтали).
4. Таблица оформляется (тёмная тема, сетка, выравнивание) и рисуется в PNG
   через `Pillow`.

Пакет `painter` — самодостаточный рендерер таблиц на Pillow, перенесённый из
проекта FMS-bot; здесь он отвязан от базы данных и работает напрямую с Excel.

## Примечание

Пример `input/05.09.2026.xlsx` и изображения в `output/` содержат реальное
школьное расписание с фамилиями учителей — приведены как демонстрация работы.
